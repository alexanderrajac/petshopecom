# <img src="/frontend/public/logo192.png" width="40" alt="Logo" /> Petizen | Modern Pet Health, Food & Adoption Startup

Petizen is a modern full-stack pet marketplace and wellness ecosystem built with the **MERN** stack (MongoDB, Express, React, Node.js) and Redux Toolkit. It provides vet-formulated fresh pet food, certified healthy adoptable pets, organic treats, brain puzzles/toys, and wellness essentials.

---

## 🚀 Startup Features

### 🛒 Comprehensive Pet Marketplace & Categories
- **🍖 Pet Food & Nutrition:** Freeze-dried raw bites, grain-free kibble, and puppy/kitten growth stews.
- **🐾 Pets & Adoption:** Certified adoptable puppies (Golden Retrievers), kittens (British Shorthair), and bunnies with health, vaccination, and microchip profiles.
- **🥓 Treats & Chews:** 100% natural, single-ingredient Himalayan yak chews and freeze-dried chicken liver bites.
- **🎾 Toys & Brain Play:** Interactive feather wands, indestructible chew bones, and smart rolling lasers.
- **🛁 Wellness & Grooming:** Organic colloidal oatmeal shampoos, calming remedies, and de-shedding tools.
- **🦮 Gear & Beds:** Orthopedic memory foam pet beds and no-pull reflective safety harnesses.
- **🎁 Seasonal Specials:** Festive holiday toys and apparel sets.

### 🌟 High-Converting Startup UX & UI
- **Interactive Pet & Food AI Matcher:** Quick quiz widget on the homepage matching pets to food, toys, and care products.
- **Autoship Subscription:** 15% discount for recurring pet food delivery with flexible scheduling.
- **Free Shipping Progress Tracker:** Visual indicator in the shopping cart towards the $35 free shipping threshold.
- **Trust Badges & Reviews:** 100% Vet-approved sourcing, 24/7 licensed vet advisory, and verified buyer reviews.
- **Modern Typography & Glassmorphism:** Powered by Google Fonts (*Plus Jakarta Sans* & *Inter*), warm amber/terracotta palette, and responsive mobile navigation.

## 🛠️ Tech Stack

- **Frontend:** React 18, React Router v6, Redux Toolkit, React-Bootstrap, React Icons, React-Toastify.
- **Backend:** Node.js, Express, MongoDB (with persistent embedded fallback via `mongodb-memory-server`), Mongoose, JWT Authentication, Multer.
- **Payments:** PayPal REST Integration & Sandbox support.

---

## ⚡ Quick Start

```bash
# 1. Install root dependencies
npm install

# 2. Install frontend dependencies
npm install --prefix frontend

# 3. Launch full stack (Frontend :3000 | Backend :5001)
npm run dev
```
